# 以物件儲存保存設定與權杖

可以使用 S3 相容的物件儲存服務來存放設定與驗證資料。

**環境變數**

| 變數                     | 必填 | 預設值       | 說明                                                                                                   |
|--------------------------|------|--------------|--------------------------------------------------------------------------------------------------------|
| `MANAGEMENT_PASSWORD`    | 是   |              | 管理網頁介面的密碼（啟用遠端管理時必填）。                                                             |
| `OBJECTSTORE_ENDPOINT`   | 是   |              | 物件儲存端點。可加上 `http://` 或 `https://` 指定協定（省略時使用 HTTPS）。                            |
| `OBJECTSTORE_BUCKET`     | 是   |              | 存放 `config/config.yaml` 與 `auths/*.json` 的 Bucket。                                                |
| `OBJECTSTORE_ACCESS_KEY` | 是   |              | 物件儲存帳戶的存取金鑰 ID。                                                                            |
| `OBJECTSTORE_SECRET_KEY` | 是   |              | 物件儲存帳戶的私密存取金鑰。                                                                           |
| `OBJECTSTORE_LOCAL_PATH` | 否   | 目前工作目錄 | 本機鏡像的根目錄；伺服器會寫入 `<值>/objectstore`。未設定時，預設為目前工作目錄。                      |

**運作方式**

1. **啟動：** 解析端點（依前綴判斷協定），以 path-style 模式建立 MinIO 相容用戶端；Bucket 不存在時會自動建立。
2. **本機鏡像：** 在 `<OBJECTSTORE_LOCAL_PATH 或當前工作目錄>/objectstore` 維護一份可寫入的快取，鏡像 `config/config.yaml` 與 `auths/`。
3. **初始化：** Bucket 中沒有 `config/config.yaml` 時，伺服器會複製 `config.example.yaml`、上傳，並作為初始設定使用。
4. **同步：** 設定檔或驗證檔的變更會上傳到 Bucket，遠端的更新也會同步回本機磁碟，讓檔案監看與管理 API 保持一致。
